# 修正企画書：自己組織的金融市場シミュレーター（発展版）

## 1. 企画概要
本プロジェクトでは、投資家の心理伝播（空間型セルオートマトンモデル）と、実際の市場取引（確率的反応系 ARMS）、そして中央銀行の政策金利介入を組み合わせた多層的な動的フィードバックループを持つ景気循環モデルを構築します。
市場の「緩やかな上昇（ブル）」「バブル」「パニック（ベア）」「回復」のサイクルを数理的に再現し、政策介入（利上げ・利下げ）が市場の安定化にどのように寄与するかをシミュレーション・分析します。

---

## 2. システム1：空間型投資家心理モデル（セルオートマトン）

二次元格子（グリッド）上に配置された投資家エージェントの相互作用をモデル化します。

### エージェントの状態
各格子（エージェント）は以下の3つの状態のいずれかをとります。
* **楽観（1）**：積極的に株を買いたい状態
* **中立（0）**：様子見の状態
* **悲観（-1）**：株を売りたい、または現金で持っておきたい状態

### 状態の伝播ルール
1世代（ステップ）ごとの更新ルールは以下の通りです。
1. 各エージェント $i$ は、自身の周囲3×3マス（隣接するエージェントと自分自身）の中からランダムに1つのエージェント $j$ を参照します。
2. 参照したエージェント $j$ の状態に応じて、エージェント $i$ は次の世代で自身がどの状態になるかを確率的に決定します。
3. 遷移確率（楽観になる確率 $P_{楽観}$、中立になる確率 $P_{中立}$、悲観になる確率 $P_{悲観}$）は、中央銀行が決定する**金利 $r$** によって動的に変化します。
4金利は初期の値を下にシステム２の株価を元に株価が高ければ高くなり、低ければ低くなるように変わるような変数にする

### 金利 $r$ による基本確率 $(p_1, p_2, p_3)$ の定義
金利 $r$（通常 $-1.0 \le r \le 1.0$ の範囲で変動）に基づき、基本確率を以下のように定義します。
* $p_1 = 0.33 - 0.2 \times r$ （金利が高いと楽観のベース確率が減少）
* $p_2 = 0.34 - 0.1 \times r$ （金利が高いと中立のベース確率が減少）
* $p_3 = 0.33 + 0.3 \times r$ （金利が高いと悲観のベース確率が増加）

> [!NOTE]
> **確率の境界値保護（クリッピング）**
> 金利 $r$ が極端な値になった場合に確率が 0 未満や 1 を超えないよう、各確率は以下のように $0 \le p \le 1$ に制限し、かつ和が 1 になるように正規化します。
> 例：各 $p_i$ を計算後、$\max(0, p_i)$ とし、その総和で割ることで確率分布とします。

### 同調感度 $\theta$ を用いた遷移確率の決定
同調バイアス（他人の意見に流されやすい性質）を表現するため、同調感度パラメータ $\theta$（$0 \le \theta \le 1.0$）を導入します。

各エージェントは：
1. 確率 $\theta$ で、参照した相手の状態と同調します。
2. 確率 $(1 - \theta)$ で、中央銀行の金利 $r$ に基づく基本確率ベクトル $P_{base} = (p_1, p_2, p_3)$ に従います。

具体的には、遷移確率 $(P_{楽観}, P_{中立}, P_{悲観})$ は参照した相手の状態に応じて以下のように決定されます：
* **楽観（1）を参照した場合**：
  * $P_{楽観} = \theta + (1 - \theta) \times p_1$
  * $P_{中立} = (1 - \theta) \times p_2$
  * $P_{悲観} = (1 - \theta) \times p_3$
* **中立（0）を参照した場合**：
  * $P_{楽観} = (1 - \theta) \times p_1$
  * $P_{中立} = \theta + (1 - \theta) \times p_2$
  * $P_{悲観} = (1 - \theta) \times p_3$
* **悲観（-1）を参照した場合**：
  * $P_{楽観} = (1 - \theta) \times p_1$
  * $P_{中立} = (1 - \theta) \times p_2$
  * $P_{悲観} = \theta + (1 - \theta) \times p_3$

## 3. システム2：確率的反応系（ARMS）による市場取引モデル

市場に存在する「マネー（現金資金）」と「株（株式価値）」の移動を、化学反応に見立てた確率的反応系（ARMS）で表現します。

### 状態変数（分子）
* $M$（Money）：市場で投資に回せるアクティブな現金量
* $S$（Stock）：市場の株式総価値（株価の代替指標）
* $B$（Bond）：安全資産（銀行預金や債券に眠る固定資金）

### 反応ルール（取引ルール）と反応定数
市場心理指数 $I$ を以下のように定義します。
$$\text{市場心理指数 } I = \frac{\text{楽観エージェント数} - \text{悲観エージェント数}}{\text{全エージェント数}}$$
※ $I$ は $-1.0$ （極度の悲観・パニック）から $+1.0$ （極度の楽観・バブル）の範囲をとります。

ARMSにおける反応式と、心理指数 $I$、金利 $r$ による反応定数 $k$ の変化は以下の通りです。

1. **買い注文（マネーから株への移行）**
   $$M \xrightarrow{k_{buy}} S$$
   * 反応定数：$k_{buy} = k_0 \times (1.0 + \alpha \times I)$
   * 説明：市場心理が楽観的（$I > 0$）であるほど、資金が株式に流入する速度が上がります。
2. **売り注文（株からマネーへの戻り）**
   $$S \xrightarrow{k_{sell}} M$$
   * 反応定数：$k_{sell} = k_0 \times (1.0 - \alpha \times I)$
   * 説明：市場心理が悲観的（$I < 0$）であるほど、株式が売却され現金化される速度が上がります。
3. **安全資産への退避（金利引き締めによる資金吸収）**
   $$M \xrightarrow{k_{bond\_in}} B$$
   * 反応定数：$k_{bond\_in} = \beta \times \max(0, r)$
   * 説明：金利 $r$ が高くなると、リスク資産市場から安全資産（預金等）へ資金が流出します。
4. **安全資産からの還流（利下げによる資金供給）**
   $$B \xrightarrow{k_{bond\_out}} M$$
   * 反応定数：$k_{bond\_out} = \beta \times \max(0, -r)$
   * 説明：金利 $r$ がマイナス（または低金利）になると、安全資産から株式市場の原資となるマネーへ資金が戻ります。

## 4. 中央銀行の政策金利介入モデル（フィードバック）

中央銀行は市場を安定化させるため、株価 $S$ の過熱度（バブル）や急落（パニック）を監視し、政策金利 $r$ を動的に調整します。

### 金利調整ルール（簡易テイラー・ルール）
毎ステップ、以下のルールで次ステップの金利 $r_{t+1}$ を更新します。
$$r_{t+1} = r_t + \gamma_1 \times (S_t - S_{target}) + \gamma_2 \times I_t$$
* **$S_{target}$**：市場が安定しているとみなす目標株価水準
* **$\gamma_1, \gamma_2$**：調整感度（介入の強さを示すパラメータ）

* **利上げのロジック**：株価が目標を大きく超える（$S_t > S_{target}$）か、市場が過度に楽観的（$I_t > 0$）な場合、金利 $r$ を上げて市場を冷却します。
* **利下げのロジック**：株価が暴落する（$S_t < S_{target}$）か、市場がパニック（$I_t < 0$）な場合、金利 $r$ を下げて市場に資金を供給します。

各ステップで、反応方程式またはギレスピー・アルゴリズム（Gillespie algorithm：確率的な化学反応シミュレーション手法）に則り、$M, S, B$ の量を確率的に増減させます。

### 3. メインループ
1. 空間エージェントの状態更新（金利 $r$ に依存）
